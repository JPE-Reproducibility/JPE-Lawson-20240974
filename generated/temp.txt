           Overview

           The code in this replication package contains 4 folders of Matlab code which calibrate and simulate the
           models used in the paper, and 2 folders of R code which generates a number of the ffgures in the paper.
           These code ffles generate the results found in 8 tables and 12 ffgures in the paper, and the replicator should
           expect it to take about 36 hours to run all of the Matlab code if run in parallel, and less than a minute to
           run the R code.


           Data Availability and Provenance Statements

           5 of the 6 folders of code do not directly use any data (they do use results from the empirical analysis
           described in the Stata/SAS section of the replication package). The “R Figures A2-A3” folder uses data that
           were publicly accessible online. No registration, membership, application procedure or monetary payment
           was required to obtain the authors’ source ffles.

           Description of Programs/Code

              •The replication archive contains 4 Matlab folders, 3 of which contain the code needed to generate
                the results for 3 different speciffcations of the model that are presented in the paper; the “Sensitivity
                Speciffcations” folder is further subdivided into 7 sub-folders, each of which contains the code needed
                to generate the results for one of the 7 sensitivity analyses considered in Appendix G of the paper.
                These 10 folders – the 3 folders entitled “Baseline Speciffcation”, “Unemployment Speciffcation”, and
               “Unproductive Managers Speciffcation”, and the 7 sub-folders in the “Sensitivity Speciffcations” folder –
                will be referred to as “analysis folders” in what follows.
                  –Each analysis folder is divided into 3 sub-folders: “Code” contains the Matlab code, “Data” is
                   initially empty but will eventually contain the Matlab .mat ffles that are created by the Matlab
                   code and used in some code ffles, and “Output” is initially empty but will eventually contain the
                   ffnal output ffles that are used in the paper. In each analysis folder, there is one master ffle of
                   Matlab code, entitled “Main.m”, which executes all of the code in that analysis folder. If run
                   on its own, Main.m should take between 12 and 30 hours in each analysis folder (except for the
                   “Unproductive Managers Speciffcation” folder, which only takes about 10 minutes); if the Main.m
                   in all 10 analysis folders are executed simultaneously, the code should take about 36 hours to run.
                   In each Main.m ffle, lines 5-7 deffne the paths for the Code, Data, and Output folders, with line 3
                   deffning the base path on the computer we used; replicators will need to replace line 3 in each
                   Main.m ffle with the appropriate path on their own computer.
              •The replication archive also contains 2 R folders, the ffrst of which is entitled “R Simulation Figures”,
                which is divided into 2 sub-folders: “Code” contains the R scripts, and “Output” is initially empty
                but will eventually contain the PDF ffles for a number of ffgures in the paper. In the Code sub-folder,
               “Main.R” is the master script which calls all of the other scripts, and should take less than a minute to
                run; each of the other scripts loads the R packages that are required in that script. Line 2 of Main.R
                deffnes the main path for the replication folder, and replicators will need to replace this line with the
                appropriate path on their own computer.
              •The second R folder is entitled “R Figures A2-A3”, which is divided into 3 sub-folders: “Code” contains
                the R scripts, “Data” contains the 2 original XLSX data ffles and the 2 analysis CSV data ffles (as
                well as a CSV ffle detailing the third-party rights to the data), and “Output” is initially empty but
                will eventually contain the PDF ffles for Figures A2 and A3 in the appendix of the paper. In the Code
                sub-folder, “Main.R” is the master script which calls all of the other scripts, and should take less than
                a minute to run; each of the other scripts loads the R packages that are required in that script. Line 2
                of Main.R deffnes the main path for the replication folder, and replicators will need to replace this line
                with the appropriate path on their own computer.


           Instructions to Replicators

              •In the “Baseline Speciffcation” folder, run the “Main.m” ffle in the “Code” sub-folder, updating the
                path on line 3 to the appropriate folder on your computer. This will run all of the code for the baseline
                speciffcation of the model, and generate PDFs and CSV ffles in the “Output” sub-folder for Figures 3,
                4, 5, 6, 7, 8, F1, and F2, as well as Tables 5, 6, F1, and F2. For Figures 6, 7, 8, and F2, the CSV ffles
                are used to produce the ffgures using R in the second-last step below.
              •In the “Sensitivity Speciffcations” folder, each sub-folder represents a different sensitivity speciffcation,
                and thus a different column of Table G1 and a different panel of Figure G1; all sub-folders are labelled
                with the column number as well as a description of the speciffcation.
                  –In each sub-folder, run the “Main.m” ffle in the “Code” sub-sub-folder, updating the path on line
                   3 to the appropriate folder on your computer. This will run all of the code for the given sensitivity
                   speciffcation of the model, and generate the CSV ffle for the given column of Table G1 in the
                   “Output” sub-folder, as well as the CSV ffle which is used to produce the given panel of Figure G1


                                                  3                   using R in the second-last step below.
              •In the “Unemployment Speciffcation” folder, run the “Main.m” ffle in the “Code” sub-folder, updating
                the path on line 3 to the appropriate folder on your computer. This will run all of the code for the
                unemployment speciffcation of the model, and generate the CSV ffles for Table H1 and the upper panel
                of Table H2 in the “Output” sub-folder, as well as the CSV ffle which is used to produce the ffgure in
                the lower panel of Table H2 using R in the second-last step below.
              •In the “Unproductive Managers Speciffcation” folder, run the “Main.m” ffle in the “Code” sub-folder,
                updating the path on line 3 to the appropriate folder on your computer. This will run all of the code
                for the unproductive managers speciffcation of the model, and generate the CSV ffle for Table I1 in the
               “Output” sub-folder, as well as the CSV ffle which is used to produce Figure I1 using R script in the
                second-last step below.
              •In the “R Simulation Figures” folder, run the “Main.R” ffle in the “Code” sub-folder, updating the
                working directory on line 2 to the appropriate folder on your computer. This will run all of the code
                that uses the CSV ffles produced above to generate PDF ffles for Figures 6, 7, 8, F2, G1, and I1, and
                the ffgure in the lower panel of Table H2.
              •In the “R Figures A2-A3” folder, run the “Main.R” ffle in the “Code” sub-folder, updating the working
                directory on line 2 to the appropriate folder on your computer. This will run all of the code that uses
                the data in the “Data” sub-folder to generate PDF ffles for Figures A2 and A3.
